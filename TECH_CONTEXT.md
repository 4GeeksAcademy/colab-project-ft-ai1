# Base Rules

- **Solid SEO:** Use semantic structure, indexable content, SEO best practices, and appropriate Schema.org structured data.
- **Fully responsive:** Support mobile, tablet, and desktop layouts.
- **Accessible:** Implement accessibility features in accordance with WCAG guidelines.
- **Tailwind CSS only:** Use Tailwind CSS for all styling.
- **No other technologies:** Do not introduce or use any additional styling technologies or frameworks.
